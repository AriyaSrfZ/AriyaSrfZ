## 2. Active Production Workflows

### 1. Daily Routine - Freelance & Bounty Hunter
* **File**: `workflows/01_daily_freelance_and_bounty_hunter.json`
* **Trigger**: Scheduled every morning at **09:00 AM (Asia/Tehran)** + Manual Trigger.
* **Pipeline**:
  1. Aggregates live high-value leads across LinkedIn (Dubai Solutions Architect openings, inbound collaboration leads), Reddit (`r/developers_hire`, `r/forhire` automation contracts), and Web3/Solana dev bounties (Superteam Earn).
  2. Formats a structured HTML intelligence dispatch.
  3. Pushes the morning briefing directly to **@ariajobwantbot** on Telegram (`chat_id: 109715946`).

### 2. Antigravity Agentic Webhook Engine
* **File**: `workflows/02_antigravity_webhook_receiver.json`
* **Trigger**: Webhook POST at `/webhook/antigravity`
* **Pipeline**:
  1. Listens for event dispatches generated by Antigravity frontends and browser daemons.
  2. Forwards payloads to colocated Ollama (`http://192.168.1.136:11434/api/generate`) with `llama3-abliterated:latest`.
  3. Returns synchronous structured JSON responses back to the Antigravity application layer.

### 3. Infrastructure & Ollama Heartbeat Monitor
* **File**: `workflows/03_infrastructure_heartbeat_monitor.json`
* **Trigger**: Interval execution every 30 minutes.
* **Pipeline**:
  1. Pings local Ollama model registry (`11434`) and cluster health.
  2. Logs health state and triggers automated alerts if services degrade.

### 4. Autonomous Career Engine (Multi-Site + ATS + Executive Recon)
* **File**: `workflows/04_full_autonomous_job_hunt_and_outreach_pipeline.json`
* **Workflow ID in n8n**: `UiBnSNo38poN2946`
* **Architecture**: 15 distinct nodes across 5 parallel ingestion lanes (RemoteOK, Jobicy, GitHub Bounties, LinkedIn Target Pipeline, Email Monitor) feeding into Company Recon, 200-char Connection Drafter, Local Ollama ATS Engine, and Telegram Executive Dispatch.

## 4. Quickstart & Operations

### Starting the Local Tunnel
If accessing from the local workstation, ensure port 5678 is routed:
```bash
chmod +x scripts/*.sh
./scripts/start_tunnel.sh
```

### Syncing & Importing Workflows
To push updated workflow definitions from Git directly into the running n8n engine:
```bash
./scripts/import_all_workflows.sh
```
